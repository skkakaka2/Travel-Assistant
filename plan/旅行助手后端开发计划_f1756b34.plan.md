### 第二阶段：用户管理模块（优先级最高）

**功能范围：**

- 注册登录（JWT认证）
- 个人信息（昵称、头像、手机号等）
- 家庭位置（集成百度地图，支持经纬度存储）
- 车辆绑定（用户与车辆的关联关系）

**数据表设计：**

```sql
-- 用户表
CREATE TABLE t_user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    nickname VARCHAR(50),
    avatar VARCHAR(255),
    phone VARCHAR(20),
    email VARCHAR(100),
    status TINYINT DEFAULT 1,
    created_at DATETIME,
    updated_at DATETIME
);

-- 家庭位置表
CREATE TABLE t_home_location (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    name VARCHAR(100),
    address VARCHAR(255),
    longitude DECIMAL(10,7),
    latitude DECIMAL(10,7),
    is_default TINYINT DEFAULT 0,
    created_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES t_user(id)
);

-- 用户车辆绑定表
CREATE TABLE t_user_vehicle (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    vehicle_id BIGINT NOT NULL,
    is_default TINYINT DEFAULT 0,
    bind_time DATETIME,
    FOREIGN KEY (user_id) REFERENCES t_user(id),
    FOREIGN KEY (vehicle_id) REFERENCES t_vehicle(id)
);
```

### 第四阶段：行程管理模块

**功能范围：**

- 行程创建（起点、终点、路线规划）
- 行程记录（里程、时间）
- 集成百度地图 API 进行路线计算

**数据表设计：**

```sql
-- 行程表
CREATE TABLE t_trip (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    vehicle_id BIGINT,
    title VARCHAR(100),
    start_location VARCHAR(255),
    start_longitude DECIMAL(10,7),
    start_latitude DECIMAL(10,7),
    end_location VARCHAR(255),
    end_longitude DECIMAL(10,7),
    end_latitude DECIMAL(10,7),
    distance DECIMAL(10,2),              -- 里程(公里)
    duration INT,                         -- 时长(分钟)
    status TINYINT DEFAULT 0,
    start_time DATETIME,
    end_time DATETIME,
    created_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES t_user(id),
    FOREIGN KEY (vehicle_id) REFERENCES t_vehicle(id)
);
```

### 第五阶段：活动管理模块

**功能范围：**

- 活动创建与管理
- 活动参与

**数据表设计：**

```sql
-- 活动表
CREATE TABLE t_activity (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    creator_id BIGINT NOT NULL,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    location VARCHAR(255),
    longitude DECIMAL(10,7),
    latitude DECIMAL(10,7),
    start_time DATETIME,
    end_time DATETIME,
    max_participants INT,
    status TINYINT DEFAULT 1,
    created_at DATETIME,
    FOREIGN KEY (creator_id) REFERENCES t_user(id)
);

-- 活动参与表
CREATE TABLE t_activity_participant (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    activity_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    join_time DATETIME,
    status TINYINT DEFAULT 1,
    FOREIGN KEY (activity_id) REFERENCES t_activity(id),
    FOREIGN KEY (user_id) REFERENCES t_user(id)
);
```

| POST   | /api/user/avatar              | 上传头像     |
| GET    | /api/user/home-locations      | 获取家庭位置列表 |

## 开发顺序总结

1. **项目初始化** - Maven 依赖、配置文件、公共组件
2. **用户管理** - 认证授权、个人信息、家庭位置、车辆绑定
3. **车辆管理** - 车辆型号、油耗管理
4. **行程管理** - 行程记录、百度地图集成
5. **活动管理** - 活动创建与参与
6. **费用管理** - 费用记录与统计
7. **站内信** - 消息通知
8. **文件存储** - 本地存储服务
