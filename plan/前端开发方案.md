# 旅行助手前端开发方案

## 一、技术栈

| 类别 | 选择 |
|------|------|
| 框架 | Vue 3 + TypeScript + Vite |
| UI组件库 | Element Plus |
| 状态管理 | Pinia |
| HTTP请求 | Axios |
| 地图服务 | 百度地图 |
| 图表库 | ECharts（费用统计） |
| 布局 | 顶部导航 + 响应式 |

## 二、主题风格

| 方面 | 设计方案 |

| **主色调** | 橙色系 (#FF6B35 / #F7931E) |
| **辅助色** | 黄色(#FFD166)、珊瑚色(#FF8C61) |

### 2.3 设计特点

| 特点 | 实现方式 |
|------|----------|
| **活泼图标** | 使用 Emoji 或 Lucide Icons 彩色图标 |
| **渐变点缀** | 按钮、卡片头使用橙色渐变 |
| **圆角设计** | 大圆角(12-16px)，柔和友好 |
| **微动效** | 卡片悬浮、按钮点击有弹性动画 |
| **趣味空状态** | 空数据页面使用插画+友好文案 |

### 2.4 暗/亮模式

| 模式 | 背景色 | 文字色 | 卡片色 |
|------|--------|--------|--------|
| 亮色模式 | #FFF8F0 → #FFF | #333 | #FFF + 阴影 |
| 暗色模式 | #1A1A2E → #16213E | #EAEAEA | #252541 |

## 七、后端API对接

### 7.1 API基础配置

```typescript
// 开发环境
VITE_API_BASE_URL=http://localhost:8080

// 生产环境
VITE_API_BASE_URL=/api
```

### 7.2 认证机制

- 使用 JWT Token 认证
- Token 存储在 localStorage
- 请求头自动携带 `Authorization: Bearer {token}`
- Token 过期自动跳转登录页

### 7.3 API模块清单

| 模块 | 文件 | 主要接口 |
|------|------|----------|
| 认证 | api/auth.ts | login, register |
| 用户 | api/user.ts | getProfile, updateProfile, updateAvatar, getHomeLocations, addHomeLocation, bindVehicle |
| 车辆 | api/vehicle.ts | getVehicles, getVehicle, createVehicle, updateVehicle, deleteVehicle |
| 行程 | api/trip.ts | getTrips, getTrip, createTrip, updateTrip, deleteTrip, startTrip, endTrip, cancelTrip |
| 活动 | api/activity.ts | getActivities, getActivity, createActivity, updateActivity, deleteActivity, joinActivity, quitActivity, cancelActivity |
| 费用 | api/expense.ts | getExpenses, getExpense, createExpense, updateExpense, deleteExpense, getStatistics |
| 消息 | api/message.ts | getMessages, getMessage, markRead, markAllRead, deleteMessage, getUnreadCount |
| 地图 | api/map.ts | geocode, reverseGeocode, getRoute |
| 文件 | api/file.ts | upload, uploadAvatar |

## 八、注意事项

1. **跨域处理**：开发环境通过 Vite proxy 代理到后端
2. **Token刷新**：暂未实现Token刷新机制，后续可扩展
3. **地图API**：需要在百度地图开放平台申请AK
4. **响应式断点**：768px(平板)、1024px(桌面)
5. **暗色模式**：使用 CSS 变量 + Element Plus 暗色主题
